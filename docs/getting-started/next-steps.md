# Next Steps

Choose a path based on the problem you are solving:

- Build feature modules and explicit exports in [Fundamentals](../fundamentals/index.md).
- Add routes, binding markers, and request context in [HTTP](../http/index.md).
- Add validation, guards, interceptors, and filters in the
  [request pipeline](../pipeline/index.md).
- Configure sources and secrets with [Settings](../techniques/settings.md), then
  add [structured logging](../techniques/logging.md).
- Use provider overrides and ASGI lifecycle tests in
  [Testing Applications](../techniques/testing.md).
- Serve and deploy an application through [CLI and ASGI](../operations/cli-and-asgi.md).
- Generate OpenAPI 3.1 and Swagger UI with the optional
  [OpenAPI integration](../openapi/index.md).
- Select CQRS, SQLAlchemy, microservices, or persistent streams from the
  [package decision matrix](../packages.md).

Continue with the in-memory [Task API tutorial](../tutorials/task-api.md). It
shows module composition, typed settings, request scope, a guard, validation, a
domain filter, and provider overrides without claiming production persistence
or authentication. The [learning paths](../tutorials/index.md) then lead to CQRS
and distributed examples.
