# tori-py-cqrs

`tori-py-cqrs` integrates the framework-neutral CQRS core with Tori Py modules,
dependency injection, handler discovery, scopes, and application lifecycle.

```bash
uv add tori-py-cqrs
```

The package is beta and follows independent Semantic Versioning. See the
[package source](https://github.com/mikeoz32/tori-py/tree/main/packages/tori-py-cqrs),
[documentation](https://github.com/mikeoz32/tori-py/tree/main/docs), and
[changelog](https://github.com/mikeoz32/tori-py/blob/main/CHANGELOG.md).
